💻 Cara Menjalankan Website (Di Laptop / Local)

1
Buka Aplikasi Laragon
Cari icon Laragon (warna biru) di laptop kamu.
2
Nyalakan Server
Klik tombol "Start All". Pastikan Apache dan MySQL sudah menyala hijau.
3
Buka di Browser
Buka Google Chrome, lalu ketik alamat ini: http://websiteku.test
4
Login ke Admin (Bila Perlu)
Untuk mengubah materi atau quiz, masuk ke http://websiteku.test/wp-admin.

🤖 Cara Kerja Chatbot AI (Jawab Pertanyaan Dosen)

Kalau dosen tanya: "Meli, gimana sih cara kerja Chatbot kamu?". Jawab dengan alur ini ya:

  1. Siswa mengetik pertanyaan di Website (Frontend).
  2. Pertanyaan itu dikirim ke n8n (sebagai jembatan pengatur lalu lintas data).
  3. Di dalam n8n, terjadi proses RAG (Retrieval-Augmented Generation):
    • Sistem mencari materi TIK yang nyambung di database pintar bernama Supabase (Vector Database).
  4. Materi yang ditemukan + pertanyaan siswa diserahkan ke Google Gemini (Otak AI).
  5. Google Gemini membaca materi tersebut, lalu merangkai jawaban yang ramah anak SD.
  6. Jawaban dikirim balik ke website dan muncul di layar siswa. ✨

💡 Tips Rahasia untuk Demo Sidang (Auto Nilai A!)

  • Tunjukkan Fallback System: Pamerkan ke dosen! Kalau internet tiba-tiba mati atau server n8n *down*, chatbot kamu tetap bisa menjawab pertanyaan dasar karena punya sistem darurat (Javascript Lokal). Ini nilai plus banget!
  • Coba Tanyakan Hal di Luar Pelajaran: Coba tanya chatbot: "Siapa presiden Indonesia?". Chatbot akan menolak dengan sopan karena sudah diprogram khusus (Prompt Engineering) untuk hanya menjawab materi TIK. Dosen pasti suka keamanan ini!
  • Perlihatkan Fitur Kuis: Setelah baca materi, klik tombol Quiz dan tunjukkan animasi interaktif saat menjawab soal.
